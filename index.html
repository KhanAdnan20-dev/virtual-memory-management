Algorithm Descriptions

FIFO

First-In, First-Out replaces the page that has been in memory the longest. A queue tracks the order pages entered memory. Simple to implement but may evict heavily-used pages.

LRU

Least Recently Used replaces the page that has not been accessed for the longest time. It assumes that pages used recently will likely be used again soon (temporal locality).

Optimal

Optimal (Bélády's) replaces the page that will not be used for the longest time in the future. It produces the minimum possible page faults, but requires future knowledge of the reference string, so it serves as a theoretical benchmark.
